1. 🔥 Prioridade Alta — Experiência Multi-dispositivo, Docker & Rede Local (LAN)
Proxy Reverso no Express (server.ts) para acesso via Celular/Tablet:
Hoje, StudioScreen.tsx, useHeraldryStore.ts e useWorldMapStore.ts apontam os modos Docker para http://localhost:8080, 8081 e 8083. Se você abrir o RollDeck em um tablet na mesa pelo IP da máquina (ex.: http://192.168.1.x:3000), os iframes em localhost falharão no tablet.
Solução: Adicionar rotas de proxy no server.ts (ex.: /apps/fmg, /apps/armoria, /apps/silverbullet) encaminhando para os serviços da rede rolldeck-network do Docker, ou resolver o hostname dinamicamente a partir de window.location.hostname.
Atualizar o container rolldeck-app com o novo HEALTHCHECK:
Corrigimos o HEALTHCHECK no Dockerfile após o último up, então vale rodar npm run docker:build && npm run docker:up para que o container passe de unhealthy para healthy.
2. 💾 Prioridade Alta — Persistência no Servidor para Heráldica e Mapas
Sincronização Backend via REST API v1:
Atualmente, useHeraldryStore.ts e useWorldMapStore.ts salvam apenas no localStorage do navegador, enquanto notas, fichas e pacotes já são persistidos no servidor em /app/data.
Solução: Criar endpoints /api/v1/heraldry e /api/v1/world-maps em server/apiRouter.ts com schemas Zod em server/schemas.ts, permitindo compartilhar brasões e mapas entre mestre, jogadores e múltiplos dispositivos.
3. 🔗 Prioridade Média — Aprofundar a Integração entre os Módulos
Botão "Abrir Cidade no Watabou" com a Seed do FMG:
Em fmgImporter.ts, já extraímos b.MFCG para o texto da nota de cada cidade. Podemos transformar isso em um botão direto nas notas/cartões para abrir o Watabou no Estúdio já carregando aquela cidade específica (/apps/city-generator/index.html?seed=...).
Sincronização Direta RollDeck ➔ SilverBullet / Obsidian Vault (sem download manual):
Hoje, o WorldMapVaultDrawer.tsx baixa um .md consolidado para a máquina do usuário. Podemos adicionar um endpoint no servidor que escreva os arquivos gerados por obsidianExporter.ts direto no volume compartilhado do silverbullet (.fmg-bundle/meu_obsidian_vault), refletindo as notas em tempo real na porta 8083.
Seletor de Brasão nas Fichas de Personagem:
Os brasões salvos já aparecem nos cards de facções em ForjaAssentamentoTab.tsx, mas ainda falta um seletor em PlayerSheetsScreen.tsx para vincular um brasão do cofre como emblema da ficha ou casa nobre do personagem.
4. ⚡ Performance, Bundle & Segurança
Divisão do Bundle Principal (codeSplitting):
No último vite build, o chunk index-*.js ficou em 902.01 kB (264.67 kB gzip), disparando o alerta de chunks acima de 500 kB.
Solução: Configurar build.rolldownOptions.output.codeSplitting em vite.config.ts separando bibliotecas pesadas (three, d3-force, jszip, minisearch, motion) em vendor chunks independentes, melhorando o cache do PWA e o carregamento inicial em celulares.
Endurecimento do Sanitizador SVG:
svgSanitizer.ts já bloqueia <script>, <iframe>, <embed>, javascript: e atributos on*, mas pode ser reforçado contra <foreignObject> e <use href="data:..."> caso o cofre passe a receber SVGs de terceiros via API compartilhada.
